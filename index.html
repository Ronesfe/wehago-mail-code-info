위하고 메일 코드

세무회계 사무소 안에서 쓰는 크롬 확장 프로그램입니다. 위하고(WEHAGO) 이메일 인증 로그인 때 사용자 본인의 Gmail에서 6자리 인증 코드를 찾아 입력칸을 채웁니다. 일반에 배포하지 않습니다.

하는 일

  • 사용자가 위하고 로그인 화면에서 이메일 인증을 고르면 동작을 시작합니다.
  • 사용자 본인의 Gmail에서 위하고가 보낸 인증 코드 메일을 찾습니다.
  • 코드를 입력칸에 채웁니다. '인증' 단추는 사용자가 직접 누릅니다.
