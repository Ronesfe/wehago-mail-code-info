위하고 메일 코드 개인정보처리방침

시행일: 2026년 11월 1일

1. 읽는 정보

사용자가 허용하면 이 확장은 Google의 gmail.readonly 권한으로 사용자 본인의 Gmail을 조회합니다. 위하고 이메일 인증 화면이 열렸을 때에만, 보낸 사람이 no-reply@wehago.com이고 제목에 '로그인 인증 코드'가 들어간 최근 메일을 검색해 보낸 사람, 제목, 수신 시각, 본문을 읽고 6자리 코드를 찾습니다. 다른 메일을 찾거나 내용을 살펴보는 기능은 없습니다.

위하고 화면이 받은 응답에서는 발송 여부, 코드 유효 시간, 가려진 메일 주소, 인증 결과 코드만 읽습니다.

2. 쓰는 방법

찾은 코드는 위하고 로그인 입력칸을 채우는 데에만 씁니다. 메일 내용을 광고, 분석, 모델 학습 등 다른 목적으로 쓰지 않으며, 사람이 열람하지 않습니다.

3. 저장과 전송

  • 메일 내용과 코드는 저장하지 않습니다.
  • 메일 내용과 코드를 개발자의 서버나 제3자에게 보내지 않습니다. 이 확장에는 별도의 서버가 없습니다. 코드는 사용자의 브라우저 안에서 위하고 화면에 입력될 뿐입니다.
  • Google 접근 토큰은 브라우저 세션 저장소에 임시로 두며 브라우저를 닫으면 지워집니다. Gmail 연결 여부 표시 하나만 브라우저에 남습니다.

4. Google 사용자 데이터 정책

이 확장이 Google API에서 받은 정보의 사용과 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 권한 철회

언제든지 Google 계정의 타사 앱 연결 화면에서 이 앱의 권한을 취소할 수 있습니다. 크롬에서 확장을 제거하면 동작도 멈춥니다.
